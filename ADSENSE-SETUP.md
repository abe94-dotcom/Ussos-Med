# AdSense launch checklist

The site is prepared for an AdSense review, but ads are intentionally disabled.

Before adding ad code:

1. Create and approve the AdSense account using the final production domain.
2. Confirm the business details, contact email, and legal terms on the public policy pages are accurate for the operating jurisdiction.
3. If ads will be served to users in the EEA, UK, or Switzerland, configure a Google-certified CMP and only load ad code after the required consent signal is available.
4. Add the publisher-provided `ads.txt` line to `public/ads.txt`. Do not publish a placeholder line.
5. Add the AdSense script using the actual `ca-pub-…` publisher ID and place only clearly separated, labelled ad units on substantial editorial content pages. Never place ads on `/quote/`, `/privacy/`, `/terms/`, or the 404 page.
6. Validate the published domain in AdSense and review the Policy center before enabling automatic ads.
